AI Resume Analyzer 📄🤖

Project Overview

AI Resume Analyzer is a Python-based web application developed using Streamlit. It helps users analyze their resumes, extract important information, identify skills, and understand how well their resume matches a job requirement.

Features

- Upload resumes in PDF format.
- Extract text from PDF resumes.
- Identify technical skills from resumes.
- Analyze resume information.
- Compare resume skills with required job skills.
- Display resume analysis results through a simple web interface.

Technologies Used

- Python – Core programming language.
- Streamlit – Web application interface.
- PyPDF2 – Extract text from PDF files.
- Pandas – Data handling and processing.
- SQLite – Database management.
- CSV – Store and manage skill information.

Installation and Setup

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the Project Folder

cd AI-Resume-Analyzer

3. Install Required Packages

pip install -r requirements.txt

4. Run the Application

streamlit run app.py

The application will open in your web browser.

How to Use

1. Open the AI Resume Analyzer application.
2. Upload your resume in PDF format.
3. The application extracts the resume text.
4. It analyzes the skills and relevant information.
5. View the analysis results on the screen.
